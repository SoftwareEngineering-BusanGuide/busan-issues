# busan-guide

# 📍 부산 알리미

> 내 주변에서 일어나는 부산의 크고 작은 이슈와 날씨를, 지도와 AI 대화로 한눈에.

부산 시민과 방문객을 위한 **위치 기반 지역 이슈·날씨 안내 AI 서비스**입니다.
부산 지역 뉴스와 공공데이터를 수집해 사용자 주변의 사건·사고, 행정 소식, 날씨와 안전 정보를 지도 위에 보여주고, 자연어로 질문하면 LLM이 여러 정보를 조합해 답변합니다.

> 소프트웨어공학 팀 프로젝트

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🗺️ **내 주변 이슈 지도** | 현재 위치(부산 내)를 기준으로 주변 이슈를 지도에 표시합니다. LLM이 기사에서 장소를 추출해 좌표로 변환합니다. |
| 🕒 **이슈 타임라인** | 같은 사건의 기사를 묶어 시간순으로 보여주고, 사건의 현재 상황을 요약합니다. |
| 🌤️ **날씨·안전 알리미** | 구·군별 날씨, 예보, 미세먼지를 생활 조언과 함께 제공하고, 재난문자·기상특보를 알려줍니다. |
| 💬 **대화형 질의** | "내일 해운대 가도 괜찮을까?"처럼 물어보면, 이슈와 날씨 정보를 조합해 출처와 함께 답변합니다. |

<br>

## 🏗️ 시스템 구조

```
[사용자] ── 위치 / 질문
   │
   ▼
[Frontend] 지도 · 타임라인 · 날씨 위젯 · 채팅
   │
   ▼
[Backend API]
   │
   ├─▶ [AI 모듈] 의도 분석 → 도구 선택(Tool calling) → 답변 생성
   │        │
   │        ├─ search_nearby_issues()   주변 이슈 검색
   │        ├─ get_issue_timeline()     사건 타임라인
   │        ├─ get_weather()            구·군별 날씨
   │        └─ get_alerts()             재난문자·특보
   │
   └─▶ [DB] 뉴스 이슈 · 기사 메타데이터 · 위치 정보

[수집 파이프라인] 뉴스 수집 → 부산 기사 판별 → 분류 → 같은 사건 묶기 → 장소 추출 → DB 저장
```

## 🚀 시작하기

### 1. 레포지토리 받기

```bash
git clone https://github.com/SoftwareEngineering-BusanGuide/busan-guide.git
cd busan-guide
```

### 2. 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열어 팀에서 공유받은 API 키를 입력합니다.

> ⚠️ `.env` 파일은 절대 커밋하지 마세요. API 키는 팀 내부 채널로만 공유합니다.

### 3. 실행

> 각 모듈 구현 후 업데이트합니다.

- **Backend (FastAPI):** [`backend/README.md`](backend/README.md) 참고. `cd backend && uvicorn app.main:app --reload`

```bash
# 예시: 뉴스 파이프라인 샘플 실행
cd data/news
pip install -r requirements.txt
python pipeline.py --sample
```

## 🤝 협업 규칙

### 작업 흐름

```
Issue 생성 → 브랜치 생성 → 작업·커밋 → Push → Pull Request → 리뷰(1명 승인) → Merge
```

- `main` 브랜치에는 직접 push하지 않습니다.
- 모든 작업은 Issue에서 시작하고, PR 본문에 `Closes #이슈번호`를 적습니다.

### 브랜치 이름

| 종류 | 형식 | 예시 |
|---|---|---|
| 기능 | `feature/이슈번호-설명` | `feature/12-news-cluster` |
| 버그 | `fix/이슈번호-설명` | `fix/20-map-marker` |
| 문서 | `docs/이슈번호-설명` | `docs/5-requirements` |

### 커밋 메시지

```
종류(파트): 내용 #이슈번호
```

| 종류 | 의미 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `docs` | 문서 |
| `refactor` | 코드 구조 개선 |
| `test` | 테스트 |
| `chore` | 설정, 기타 |

예시: `feat(data): 같은 사건 기사 묶기 기능 추가 #12`

## 📚 데이터 출처

본 프로젝트는 아래 데이터와 API를 각 이용조건에 따라 사용합니다. 상세 내용은 [`docs/data-sources.md`](docs/data-sources.md)를 참고하세요.

| 데이터 | 제공 | 용도 |
|---|---|---|
| 뉴스 검색 API | 네이버 | 부산 지역 기사 제목·요약·원문 링크 |
| 긴급재난문자 | 행정안전부 (공공데이터포털) | 재난·안전 알림 |
| 단기예보 | 기상청 (공공데이터포털) | 구·군별 날씨 |
| 대기오염정보 | 한국환경공단 에어코리아 | 미세먼지 |
| 지도·로컬 API | 카카오 | 지도 표시, 장소 → 좌표 변환 |

**저작권 원칙**

- 뉴스 기사 본문은 저장하거나 제공하지 않으며, 제목·요약과 **원문 링크**만 표시합니다.
- 긴급재난문자는 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지)에 따라 **원문 그대로** 표시합니다.
- 사용자 위치 정보는 주변 검색에만 사용하며 **서버에 저장하지 않습니다.**
